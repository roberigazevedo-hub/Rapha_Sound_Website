# 🎵 Rapha Sound Website

## 📖 Sobre o Projeto

Este projeto foi desenvolvido durante meus estudos na DevClub, colocando em prática os conhecimentos adquiridos em desenvolvimento web.

O objetivo do site é fortalecer a presença digital da Rapha Sound, divulgando a loja na internet e facilitando a conexão com clientes por meio das redes sociais.

## 🚀 Tecnologias Utilizadas

- 🔶 HTML5
- 🎨 CSS3
- ⚡ JavaScript

## 🎯 Objetivos do Projeto

- Desenvolver habilidades em HTML e CSS.
- Aplicar conceitos de estruturação e estilização de páginas web.
- Criar uma página moderna para divulgação de uma empresa.
- Melhorar a experiência do usuário na navegação.

## 📱 Funcionalidades

- Apresentação da loja Rapha Sound.
- Divulgação dos produtos e serviços.
- Acesso às redes sociais.
- Layout responsivo.
